# Privacy

Puzzlebox stores game progress, puzzle sequence numbers, statistics and appearance preferences on the device using SharedPreferences. It has no account system, advertising SDK, analytics SDK, remote leaderboard, payment service or configured backend. Puzzle generation and hints work offline.

Sharing a Daily Five result opens the operating system share sheet only when the player presses Share. Clearing app storage or uninstalling the app can remove local progress. The app does not provide cloud backup or cross-device synchronization.
